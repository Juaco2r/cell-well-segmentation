# Changelog

## v1.0.0 - 2026-05-26

Initial GitHub-ready release under the name **Cell Well Segmentation**.

### Added

- PyQt5 GUI for single-image and bulk-image processing.
- Multichannel segmentation workflow with ROI-based parameter exploration.
- Cell feature extraction CSV output.
- Manders colocalization metrics.
- QuPath-compatible GeoJSON export.
- Optional DICE/IoU validation against ground-truth GeoJSON.
- Existing-output handling: reprocess, skip completed, or resume missing outputs.
- GitHub-ready metadata: README, LICENSE, CITATION.cff, Zenodo metadata, requirements, pyproject, packaging helpers.
